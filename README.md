# Apex-Logistics-and-Supply
This is a fictional company that will cover the CompTIA trifecta (A+, Network +, Security) as well as mastery of networking/foundational skills. In this home lab I will act as an Infrastructure & Systems Administrator that will repair the infrastructure.

Apex Logistics is a growing regional supply-chain and distribution firm headquartered in Chicago with 50 internal employees, remote field agents, and a newly acquired branch office.The company is currently running on a fragile, unsegmented network with legacy workgroups, no centralized identity management, and high vulnerability to perimeter breaches.

I was brought in to architect, deploy, and secure their entire on-premises IT infrastructure from the ground up using enterprise-grade virtualization, rigorous network segmentation, and proactive security monitoring.

Here is a structured pathway to building a scalable architecture and strengthening existing systems.
